# Pizzería Web

Sitio web de una pizzería con información del negocio, su menú y una página para conocer al equipo.

## Páginas

- **Inicio** (`index.html`): página principal.
- **Menú** (`menu.html`): productos de la pizzería.
- **Nosotros** (`nosotros.html`): información sobre el negocio.

## Tecnologías

- HTML
- CSS
